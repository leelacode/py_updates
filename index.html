Python 3.15 is entering the final stretch

Python 3.15.0rc2 is still the latest 3.15 preview, and it is the final planned release candidate. The Python core team says it contains roughly 144 bug fixes, build improvements and documentation changes since rc1, with no further ABI changes expected before the planned October 1 final release. This is the point where the ecosystem should be concentrating on compatibility rather than waiting for more language changes: projects that ship native extensions or wheels can test against 3.15 now, while production users should continue treating the release candidate as a preview. The headline 3.15 changes include explicit lazy imports, a built-in frozendict type, a built-in sentinel type, a dedicated profiling package, and broader free-threading support.

The Python ecosystem is getting better documentation and packaging governance

The official Python documentation became available in Persian on September 23, following the recent addition of Russian documentation. This is not a language-runtime change, but it shows continued investment in making the core documentation easier to access. On the packaging side, the newly formed Python Packaging Council held its first meeting on September 18. Its initial work is mostly organizational, with weekly meetings planned to establish how the council will operate. For developers, the practical takeaway is that packaging continues to receive dedicated governance alongside the existing Python Steering Council and PSF structures.

NumPy 2.5.3 tightens a few edge cases

NumPy 2.5.3, released September 6, is a patch release supporting Python 3.12–3.15. Among its fixes, converting fixed-width byte strings to StringDType now raises TypeError for invalid UTF-8 instead of allowing invalid bytes to survive and potentially cause undefined behavior later. It also fixes a stale MaskedArray fill value after dtype-changing ufunc operations. If you work with scientific Python, this is the kind of small maintenance release worth keeping current with, especially as Python 3.15 support becomes more important.
